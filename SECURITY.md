# Security Policy

We take security seriously and appreciate reports of vulnerabilities in Unwrap.

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in Unwrap, please responsibly disclose it by opening a private GitHub Security Advisory on the repository or contacting the repository maintainers directly rather than posting public issues or pull requests.

Please include:
- A description of the issue and potential impact.
- Detailed steps to reproduce or a minimal proof of concept.
- The platform and version of Unwrap tested.

Reports will be acknowledged promptly and investigated.
